# 阳台储能头部品牌产品参数和时间表

单文件 HTML 看板，汇总 EcoFlow / Anker / Zendure / Jackery / Marstek 五个品牌 2023 年以来的阳台储能产品参数、上市时间与官方来源链接。

- 在线访问：`index.html`（GitHub Pages 直接托管根目录）
- 本地使用：双击 `index.html` 即可，离线可用；页面内的官方链接需联网打开

## 功能

- 按品牌 / 产品类型 / 归档年份 / 并网能力 / 离网输出 / AC 输入 / 市电旁路自动切换 多维筛选
- 容量 × 最高并网输出气泡矩阵，点击圆点联动筛选表格
- 一键导出当前筛选结果为 CSV（含官方链接）

## 状态标记说明

| 标记 | 含义 |
| --- | --- |
| 支持 | 官方资料明确具备该功能 |
| 不支持 | 官方资料明确不具备或未列该功能 |
| 有条件支持 | 需配合特定机型／固件／配件，或资料存在冲突待核 |
| 待核实 | 尚未取得官方确认 |

## 数据说明

参数与来源以品牌官网、产品手册、官方 FAQ 为准，核查时间见页面页眉。数据仅供产品研究参考，以官方最新资料为准。
